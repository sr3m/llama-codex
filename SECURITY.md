# Seguridad y datos privados

No adjuntes credenciales, bases SQLite, historiales reales ni archivos de configuración personales al informar un problema. Usa ejemplos sintéticos. Los nombres de modelos y las capturas también pueden revelar rutas o servidores.

Para un fallo que exponga credenciales, usa la pestaña Security de GitHub y la opción de informar una vulnerabilidad de forma privada, si está habilitada. No publiques detalles explotables ni secretos en un issue público. Si no hay un canal privado disponible, abre un issue solicitándolo sin incluir los detalles sensibles.

El enrutador está diseñado para uso personal en loopback. No lo expongas a la red ni lo conviertas en un servicio multiusuario. El contexto enviado a un modelo cloud puede incluir mensajes anteriores del chat. No existe fallback automático a cloud.
